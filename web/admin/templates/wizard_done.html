{{.Project}} is provisioned.

Point a daemon at it and agents can start reading and writing memory.

Connect an agent

A token scopes a caller to exactly one project — that is the daemon's authorization boundary.

1. Run a daemon for this project
# --tokens maps a bearer token to a project; keep the token secret.
silod --tokens "<your-token>={{.Project}}" \
      --rqlite http://localhost:4001 \
      --admin-listen ./data/silod-admin.sock
2. Write a memory
curl -X POST http://127.0.0.1:8500/v1/write \
  -H "Authorization: Bearer <your-token>" \
  -H "Content-Type: application/json" \
  -d '{"path":"memory/notes.md","content":"'"$(printf 'hello' | base64)"'","actor":"agent-1"}'

Content is base64 in JSON, since the API carries raw bytes.

3. Read it back
curl http://127.0.0.1:8500/v1/read?path=memory/notes.md \
  -H "Authorization: Bearer <your-token>"
